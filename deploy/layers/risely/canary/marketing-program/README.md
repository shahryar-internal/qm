# Marketing program boundary

This package is a provider-free, hard-disabled CEO-only canary contract. It creates a Friday America/Los_Angeles weekly plan and an actionless Slack/QM proposal. Five weekday entries strictly alternate admissions and advancement, enforce topic and novelty cooldowns, and have versioned occurrences with exact citations.

Marketing copy is fail closed only at a lexical boundary. Weekly outlines and daily text accept only printable ASCII plus LF, with canonical whitespace. All other Unicode, CR, tabs, Unicode line separators, controls, markup, mentions, listed corporate and AI-slop terms, listed pressure or directive phrases, and listed customer or anecdote phrases are rejected. This prefilter cannot establish voice, factual safety, or coverage of unseen synonyms. All copy is tagged `untrusted_candidate`, never validated, ready, or publishable. Every substantive sentence and every outline item has an exact citation mapping. Only three fixed CTA/question/opinion templates may omit a citation. Citation mappings, citation source references, content, and revisions are included in artifact identity, program identity, idempotency, and evaluation requests.

Research data remains unresolved. It is restricted to the fixed provider/host registry and requires a receipt proposal reference, receipt hash, source reference, observation and fetch times, freshness, span, availability, trust, and research hash. The only accepted availability, trust, and receipt disposition are `unresolved`; caller-supplied fields are never authentic research. Exact citation text is not included in program artifacts.

Public daily draft creation is intentionally unreachable. Inspection provides lexical prefilters only for an exact planned occurrence, fixed private CEO Notion parent, sentence citations, and an unresolved server-time request. Creation and release require future independent trusted evaluation receipts as well as a module-private opaque trusted plan receipt. No public function mints either receipt. Missed work and stale or arbitrarily delayed moves do not create daily artifacts.

State APIs accept only immutable module-private branded programs emitted by strict builders with the fixed deployment, principal, and Slack anchors. They snapshot all values and revalidate exact schemas. A self-hashed clone cannot enter state. Evaluations create exactly eight unresolved runs: four gates across deterministic and independent-LLM origins. Every run reference derives from request, kind, origin, gate, artifact, program, and revision. Approval is an unresolved exact Slack proposal; request references are globally unique across approval and evaluation. Exact replay is idempotent and changed or cross-kind reuse conflicts.

`SNAPSHOT-MANIFEST.sha256` is the sole reproducible tree snapshot. It lists every file in `canary/marketing-program` and `test/marketing-program`, excluding itself. Its tree hash is generated with `find canary/marketing-program test/marketing-program -type f ! -name SNAPSHOT-MANIFEST.sha256 -print0 | sort -z | xargs -0 shasum -a 256 | shasum -a 256`.

This package cannot access environment or credentials, a network, database, Slack SDK, Notion SDK, filesystem, or provider. It cannot publish, execute social activity, issue trusted receipts, enable effects, or mutate a reconciliation outcome. Activation requires separately reviewed durable storage, trusted time, Slack identity/signature verification, trusted program and plan receipt bridges, independent evaluator receipts, delivery adapters, dedicated executors, revocation, and outcome-unknown reconciliation.
